# 课程分类与学生授权

电脑后台沿用原登录口令。进入“课程”后创建或编辑课程，填写课程分类，例如“A1全阶段”“A2口语”。同一分类可包含多节录播。列表支持按分类筛选；新版小程序网课中心也支持分类筛选。分类留空显示“未分类”，不会自动批量修改旧课。

观看范围有三种：

- 免费公开：游客也可观看，不设置学生名单。
- 全部登录学生：任何已登录账号可观看，不设置名单。
- 仅指定学生：只有名单中的微信账号能看到并播放。选择学生后才能发布，也可先保存草稿。

学生名单可按姓名、学校、账号或手机尾号查找并多选。确认同名学生的学校和账号标识。未显示的学生先登录填写基本资料或联系客服；也可让学生从“我的”复制账号标识，手动补充。名单不是手机号、姓名、微信号或 OpenID，必须使用对应的账号标识。

录播课使用后台上传的视频来执行授权校验。指定学生课发布时不接受外部视频直链：外部平台的链接不能由本系统控制。课程分类不等于学员分组，同一分类中的每节课分别设置权限。授权不是收费状态，不会扣费。

编辑课程、添加或移除学生后保存。学生重新进入网课中心刷新；服务器每次读取托管视频均检查当前发布状态和当前授权名单，撤销权限后旧签名链接也会拒绝。短时播放链接仍属于持有者凭据，并不能绝对防止有效期内转发、录屏或已经缓存的内容。已经公开传播的视频不能通过事后设为私有收回。

老师端消息中学生在左，老师回复在右；学生原有聊天视角保持不变。老师回复通过小程序内部消息页查看，不是公众号原生客服会话。企业微信通知仅作提醒，不等于在微信原生客服后台建立会话。

网页版后台与后端部署后即可使用新管理功能。手机老师端和学生端的分类及布局更新，需要重新上传小程序版本。
